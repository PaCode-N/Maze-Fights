# Maze Fights

A simple maze game developed in Python where you have to explore a maze and fight different enemies to escape.

This project was created to practice Python concepts such as functions, loops, conditionals, lists, dictionaries, random numbers, and user input.

## Features

- Explore a maze using keyboard controls.
- Fight randomly placed enemies.
- Different enemies with unique attacks.
- Randomized combat.
- Simple health bars.
